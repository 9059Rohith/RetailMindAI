# Preserved original project

[`pre-real-data/`](pre-real-data/) contains the complete project snapshot from commit `afe6f10`, including its original app, data generator, synthetic CSV, notebooks, SQL and documentation. It is preserved for review and comparison. The same snapshot is available as the [GitHub `archive/pre-real-data` branch](https://github.com/9059Rohith/RetailMindAI/tree/archive/pre-real-data), which can be checked out and run as the original application.

The current root application uses only the observed M5 dataset. Docker excludes this reference folder, and no code or data here is imported by the running app.
